InputLab 3D — paket fayllari
============================

inputlab3.html — asosiy (yangi) versiya: iOS dizayn, 3D klaviatura va sichqoncha,
                qo'llanma, statistika, hisobot, palitralar, PC/Noutbuk rejimlari.
inputlab2.html — asl nusxa (faqat solishtirish/ma'lumot uchun, o'zgartirilmagan).

Ishga tushirish:
  inputlab3.html faylini istalgan zamonaviy brauzerda (Chrome/Safari/Edge) oching.
  Yoki papkada quyidagi buyruq bilan mahalliy server ishga tushiring:
    node serve.js
  keyin brauzerda http://localhost:8137/inputlab3.html manzilini oching.
